# СДЭК

Доставка СДЭК для магазина на flycms. Два обработчика: курьер до двери
и пункт выдачи. Стоимость и срок считаются по тарифу для города
покупателя. После оплаты (или при статусе из настроек) плагин создаёт
заказ в СДЭК. Номер отправления показывается в разделе «СДЭК»: записать
его в отгрузку заказа контракт плагина пока не умеет.

Плагин ходит только в API СДЭК v2 (`api.cdek.ru` или учебный
`api.edu.cdek.ru`).

## Что нужно от СДЭК

Договор и ключи интеграции: личный кабинет → Интеграция, идентификатор
(Account) и пароль (Secure). Для пробы подойдёт учебная среда и общая
учётная запись с страницы протокола:
<https://www.cdek.ru/ru/integration/api/>. Учебные заказы не доставляются
и в боевой кабинет не попадают.

В форме заказа нужно поле с ролью «Местоположение». Для курьера —
поле с ролью «Адрес», для пункта выдачи — поле с ролью «Пункт выдачи»:
покупатель вписывает код пункта (его подскажет расчёт, карта виджета
СДЭК сюда не входит).

## Как включить

1. **Оформление → Способы доставки → «Добавить способ».** Название —
   как увидит покупатель. Обработчик — «flycms.cdek/door — СДЭК: курьер
   до двери» или «flycms.cdek/point — СДЭК: до пункта выдачи».
2. Вкладка **«Настройки»**:

   | Поле | Обязательное | Что вписать |
   |---|---|---|
   | Идентификатор (Account) | да | из кабинета СДЭК |
   | Пароль (Secure) | да | оттуда же; в форме потом не показывается |
   | Среда | да | «учебная» или «боевая» |
   | Город отправки | да | название или код города СДЭК |
   | Адрес отправки | нет | если курьер забирает посылку у вас |
   | Пункт приёма | нет | код пункта, откуда СДЭК забирает посылки |
   | Код тарифа | нет | пусто — 137 у курьера и 136 у пункта |
   | Вес и габариты по умолчанию | нет | для товара без веса и размеров; пусто — 1 кг и 20×15×10 см |
   | Отправитель и телефон | да | попадут в заказ СДЭК |
   | Создавать заказ при статусе | нет | код статуса магазина; пусто — когда заказ оплачен |

   Пока обязательные поля пусты, покупатель способ не видит.

3. **Плагины → СДЭК** — включите право «Читать заказы», если оно
   выключено: без него события оплаты не доходят и заказ в СДЭК не
   создаётся. Номер отправления появляется в этом разделе. Повтор
   события тот же заказ второй раз не создаёт.

Ключи можно завести один раз на службе доставки, а «до двери» и «до
пункта» сделать профилями этой службы: настройки службы дописываются
своими.

Если СДЭК не ответил, оформление не падает: способ скрывается, а если
покупатель уже выбрал его — магазин предлагает другую доставку.
