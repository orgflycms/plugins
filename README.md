# plugins — плагины flycms

Исходный код четырёх плагинов для магазинов на движке
[flycms](https://flycms.ru). Одна папка — один плагин, имя папки — полное
имя плагина `<пространство>.<имя>`.

| Плагин | Что делает |
|---|---|
| [vitams.promo](vitams.promo/) | раздел «Промокоды» в админке и скидка фиксированной суммой при корзине от порога |
| [vitams.invoice](vitams.invoice/) | способ оплаты «Счёт на оплату»: PDF с реквизитами магазина, НДС и суммой прописью, без внешних сервисов |
| [vitams.tbank](vitams.tbank/) | оплата картой и по СБП через интернет-эквайринг Т-Банка, чек 54-ФЗ |
| [vitams.tbank_invoice](vitams.tbank_invoice/) | счёт для организаций через Т-Банк Бизнес: PDF банка, оплату магазин узнаёт сам |

Как включить и настроить плагин в магазине — `README.md` в его папке.

`vitams.tbank` и `vitams.tbank_invoice` проверены только на подделке API
банка в тестах движка. До проверки на настоящих тестовых данных банка в
маркетплейс они не публикуются; что именно ещё не подтверждено — в их
`README.md`.

## Брать за образец

На примере этих плагинов видно, как устроен плагин для flycms: раздел в
админке, способ оплаты, счёт PDF, уведомления банка, опрос статуса. Берите
их за образец для своих плагинов — лицензия MIT это разрешает.

## Как устроен плагин

Плагин — папка с Go-файлами одного пакета и функцией
`Init(api sdk.API) error`. Магазин исполняет её интерпретатором: папку
кладут в папку плагинов и нажимают «Перечитать» в разделе «Плагины» —
работает, собирать ничего не нужно. В папке — только `*.go`, `README.md` и
`plugin.json`; подпапок, тестов и сторонних модулей нет.

Контракт (`sdk.API`), список доступного плагину, правила оплаты, страниц и
доступа к базе — в открытом репозитории
[github.com/orgflycms/sdk](https://github.com/orgflycms/sdk): `sdk.go` и
`README.md`. Минимальный пример — там же, `example/`.

Ключи терминалов и токены банка владелец магазина вписывает в настройки
способа оплаты. В коде плагинов секретов нет.

## Как поставить плагин в магазин

1. Положите папку плагина в папку плагинов магазина. У магазина,
   поставленного `install.sh`, это `/opt/flycms/plugins/`.
2. Откройте в админке раздел «Плагины» и нажмите «Перечитать». Если плагин
   не загрузился, ошибка будет видна там же.
3. Настройте плагин по его `README.md`. Способы оплаты подключаются в
   «Оформление → Способы оплаты → Добавить способ»; что заполнить в
   настройках способа — сказано в README плагина.

В магазины плагины попадают и из «Маркетплейса»: туда их подают заявкой
через кабинет партнёра на сайте flycms, модератор читает код и одобряет
заявку или возвращает с замечанием. Правила архива и модерации — в
`README.md` репозитория sdk.

## Откуда здесь код

Плагины разрабатываются вместе с движком, а этот репозиторий — их
опубликованная копия. Правка, сделанная только здесь, может быть
перезаписана при следующем обновлении. Для своего магазина берите код и
меняйте у себя — MIT это разрешает.
