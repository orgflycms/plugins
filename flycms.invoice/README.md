# Счёт на оплату

Способ оплаты «по счёту». Покупатель оформляет заказ, нажимает «Скачать
счёт» и получает PDF: банковские реквизиты магазина, позиции заказа, итог,
НДС, сумма прописью, срок оплаты и строки подписей. Деньги приходят
переводом на расчётный счёт магазина; когда они пришли, вы отмечаете оплату
в заказе. Плагин не обращается к банку и другим сервисам, базы данных ему
не нужно.

## Как включить

1. **Настройки → «Адрес магазина»** должен быть задан: без него способы
   оплаты плагинов покупателю не показываются.
2. **Оформление → Способы оплаты → «Добавить способ».** Название — как увидит
   покупатель («Оплата по счёту»), обработчик —
   «flycms.invoice/invoice — Счёт на оплату PDF». Сохраните.
3. Вкладка **«Настройки»** способа — реквизиты для счёта:

   | Поле | Обязательное | Что вписать |
   |---|---|---|
   | Получатель | да | название организации или ИП, как в банке |
   | ИНН | да | ИНН получателя |
   | КПП | нет | у ИП нет — оставьте пустым |
   | Адрес | нет | юридический адрес для строки «Поставщик» |
   | Банк | да | «ПАО «Сбербанк», г. Екатеринбург» |
   | БИК | да | БИК банка |
   | Корр. счёт | да | корреспондентский счёт банка |
   | Расчётный счёт | да | ваш расчётный счёт |
   | НДС | да | ставка («НДС 22%», «НДС 5%» …) или «Без НДС» — выбирается явно |
   | Срок оплаты, дней | нет | сколько дней от даты заказа ждёт счёт; пусто — 5 |
   | Руководитель | нет | фамилия и инициалы для строки подписи |
   | Бухгалтер | нет | пусто — строки подписи бухгалтера нет (удобно ИП) |
   | Примечание под счётом | нет | условия оплаты и поставки, печатаются под сроком |
   | Код поля юридического адреса | нет | код поля формы заказа с адресом покупателя; пусто — `legal_address` |

   Пока не заполнено хоть одно обязательное поле, покупатель способ не
   видит, а на вкладке написано, чего не хватает.

   НДС обязателен, хотя «Без НДС» — тоже вариант: магазин на общей системе
   налогообложения не должен выставить счёт без налога по забывчивости.
   Способ, настроенный до этого правила с пустым НДС, пропадает с витрины, а
   ссылки на счёт из старых писем отвечают «реквизиты не заполнены», пока
   ставка не выбрана.

## Покупатель — юридическое лицо

Счёт обычно нужен организациям. В магазине уже заведён тип плательщика
«Юридическое лицо» (код `company`) с полями «Организация», «ИНН», «КПП» и
«Юридический адрес» — он выключен, пока вы его не включите:

1. **Оформление → Типы плательщиков → «Юридическое лицо»** — отметьте
   «Активен» и сохраните. В оформлении заказа появится выбор «Физическое
   лицо / Юридическое лицо».
2. **Способы оплаты → ваш способ по счёту → «Ограничения»** — добавьте тип
   плательщика «Юридическое лицо». Теперь оплата по счёту видна только
   организациям, а физическим лицам — остальные способы.

В строке «Покупатель» счёта будут организация, ИНН, КПП и юридический
адрес из заказа. Если способ не ограничен и счёт скачало физическое лицо,
покупатель в счёте — имя из заказа.

Юридический адрес берётся из поля с кодом `legal_address`. Завели своё
поле адреса с другим кодом — впишите этот код в «Код поля юридического
адреса».

## Что в счёте

- **Номер** — номер заказа, **дата** — дата оформления заказа по
  московскому времени, та же, что в админке и в кабинете покупателя. Счёт
  можно скачивать сколько угодно раз: номер и дата не меняются.
- **Позиции** — строки заказа (комплект — одной строкой) и платная
  доставка услугой. Скидка заказа уже разнесена по строкам: цена — со
  скидкой, сумма строк до копейки равна сумме к оплате. Если вы завели
  оплату на другую сумму, в счёте одна строка «Оплата заказа №…».
- **НДС** — «в том числе»: налог уже в цене и к итогу не прибавляется, он
  считается один раз от суммы к оплате с округлением до копейки. «Без НДС»
  печатает «Без налога (НДС)».
- **Оплатить не позднее** — дата заказа плюс срок оплаты.
- Печати и подписи картинкой пока нет: счёт подписывают от руки или
  ставят печать после печати на бумаге.

## Где покупатель берёт счёт

Кнопка «Скачать счёт» — на странице заказа после оформления, в письме о
заказе и в личном кабинете. После оплаты кнопка пропадает, а ссылка из
письма по-прежнему отдаёт счёт: он нужен бухгалтерии и после оплаты.

## Как отметить оплату

Деньги пришли на расчётный счёт — откройте заказ, вкладка **«Оплаты»** →
«Отметить оплаченной». Заказ станет «Оплачен».
